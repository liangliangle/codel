# @codel-official/codel-darwin-x64

Platform-specific binary for [`@codel-official/codel`](https://www.npmjs.com/package/@codel-official/codel) on darwin-x64.

Do not install this package directly. Install the main package instead:

```sh
npm install -g @codel-official/codel
```

The main package will automatically pull the correct binary for your platform via `optionalDependencies`.
